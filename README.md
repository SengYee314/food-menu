# Malaysia & Co.

A static, responsive bakery menu built with HTML, CSS and vanilla JavaScript.

Run locally with `python3 -m http.server 4173 --directory dist`, then open `http://localhost:4173/`.

The menu names, descriptions and RM prices are sample content. The cart persists in the browser. Checkout is a local demonstration: no order details or payment are sent to a server.

The eight food photographs in `dist/assets/` were generated for this design and can be replaced with the bakery's own photography.
